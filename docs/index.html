API Interceptor

A library which hooks the graphics API calls of a Windows program and stores them, with their data, in workload files. Projects link it to capture a program, to read what was captured, and to build on both.

What it does

Capture

Record every call of a program into a workload file: a dumper starts the program with a DLL injected, and the hooks of the DLL write each call and what it refers to.

Replay

Execute the calls of a workload again, without the program, to check a capture. An engine, and a player window around it.

How the parts fit

One API is not all of them

DirectDraw 7 with Direct3D 7, and Direct3D 8, have deep sets of hooks, but the code is arranged for more. What depends on an API is the set of its hooks, its names for the printer, and what its structures are called in a dump; everything else (the callbacks, the data chunks, the workload file) is the same for each.

Using it from another project

A project adds this one as a submodule and builds on its libraries (add_subdirectory), or links the installed package (find_package(APIInterceptor)). See Building.
